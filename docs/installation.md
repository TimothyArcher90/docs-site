# Installation

## Before you start

You need pipx already installed. Pocket Timer installs through it.

## macOS

Run `pipx install pocket-timer`. The command is the same on every platform.

## Linux

Run `pipx install pocket-timer`. The command is the same on every platform.

## Windows

Run `pipx install pocket-timer`. The command is the same on every platform.

## Check the installation

Run `pocket --version`. If the install worked, it prints the version number.

Ready to try it? Start with [your first session](getting-started.md#your-first-session).
